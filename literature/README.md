# 先行研究ノート

## 運用ルール

- 1論文 = 1ファイル（`notes/` 以下）
- ファイル名：`著者姓_発行年_短いキーワード.md`（例：`sato_2018_ib_japan.md`）
- 英語論文は姓のローマ字表記で（例：`smith_2020_school_choice.md`）
- 参考文献として本文で引用するものは `references.bib` にも登録

## ノートのテンプレート

新しい論文を読むたびに、`notes/` 内に以下のテンプレートでファイルを作る：

```markdown
# タイトル

## 書誌情報
- 著者：
- 発行年：
- 掲載誌／出版社：
- DOI／URL：
- アクセス日：

## キーワード
- 

## 要旨（200字程度）


## 研究目的・問い


## 方法・データ


## 主要な知見
- 

## 重要な引用（ページ数付き）
> 「……」（p.XX）

## 自分の研究との関連
- 何に使えるか：
- 賛成／反論点：
- 引く章：（序論／先行研究／本論〇章など）

## 関連論文
- 
```

## ノート運用のコツ

- **全部読まない**：要旨・結論・目次で「使える／使えない」を先に判定
- **引用は必ずページ番号付きで残す**：後で探し直さないで済む
- **自分のことばで要約を書く**：丸写しは避ける
- **「使えない」と判断した論文も短くメモ**：同じ論文に再遭遇して二度読む無駄を防ぐ
