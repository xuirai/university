# 新聞・雑誌記事メモ

## 収集対象

- インター校・IB教育に関する新聞記事（朝日・読売・日経・毎日 など）
- 教育系雑誌の特集（『教育学研究』『比較教育学研究』など学術誌は `literature/` へ）
- 保護者向け教育メディア（インター校特集、体験記など）
- ウェブ記事・ブログ（信頼性を明記したうえで）

## 運用ルール

- 1記事 = 1ファイル
- ファイル名：`発行年月日_媒体_短いタイトル.md`
- 記事本文の全文コピペは著作権上避け、**要旨＋重要な引用のみ** 残す

```markdown
# 記事タイトル

- 発行日：
- 著者（記者）：
- URL／DB：（日経テレコン、朝日クロスサーチ等）
- アクセス日：

## 要旨


## 重要な引用
```
