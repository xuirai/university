# 政策文書メモ

## 収集対象

- 文部科学省「国際バカロレア」関連資料
- スーパーグローバルハイスクール（SGH）指定校・事業報告
- グローバル人材育成推進会議 報告書（2011, 2012）
- 経済産業省「グローバル人材育成」関連資料
- 各種学校制度・学校教育法の関連条文

## 運用ルール

- 1資料 = 1ファイル（ここに配置）
- ファイル名：`発行年_発行機関_短いタイトル.md`（例：`2013_mext_ib_taiou.md`）
- 原文PDFへのリンクを必ず残す
- 長い資料は「該当箇所の抜粋＋ページ番号」を引用
