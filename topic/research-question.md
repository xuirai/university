# 研究課題メモ

## 大枠テーマ

日本におけるインターナショナルスクールの需要、特に **日本人家庭の選択動機のうち「英語教育への期待」** がどう変化してきたかを、**メディア言説のテキスト分析** によって明らかにする。

## 研究の問い（仮）

**主問い**
> 日本のメディア（新聞・雑誌）におけるインターナショナルスクール関連言説、特に「英語教育への期待」に関わる語りは、2000年代以降どのように変容してきたのか？

**副問い（候補）**
- 英語教育への期待はどのような語彙・フレームで語られてきたか（「バイリンガル」「グローバル人材」「英語力」等の登場時期と推移）
- 言説の中で英語教育期待と他の動機（進学、教育観など）はどう絡み合っているか
- 制度的変化（IB推進、グローバル人材政策等）と言説の変化はどう対応しているか
- SLA 理論の視点から、言説に表れる「期待」は妥当なものか／誤解を含むか

## 決定事項

| 項目 | 内容 |
|---|---|
| アプローチ | A+B 複合：英語教育期待を軸とした動機分析 × メディア言説のテキスト分析 |
| 主データ | 新聞記事DB（日経テレコン、朝日クロスサーチ等）＋教育系雑誌 |
| 方法 | 文献・政策分析（背景）＋ テキスト分析（頻出語・共起・時期比較） |
| 対象 | 日本人家庭中心（言説の担い手・受け手として） |
| 時期スコープ | 2000年代以降（2000-2025）／戦後〜90年代は背景 |
| 地域 | 日本全国 |
| 理論的フレーム | SLA 理論、グローバル人材言説論、学校選択論 |
