## ディレクトリ構成

```
university/
├── topic/              # テーマ絞り込み・題目候補
├── literature/         # 先行研究ノート
│   └── notes/          # 1論文1ファイル
├── sources/            # 一次資料メモ
│   ├── policy/         # 政策文書（文科省等）
│   ├── statistics/     # 統計データ（IB機構、JCIS等）
│   └── media/          # 新聞・雑誌記事
├── thesis/             # 本文作業
│   └── drafts/         # 章ごとの原稿
├── references.bib      # BibTeX 参考文献DB
└── schedule.md         # 進捗管理
```

## 次にやること

1. `literature/keywords.md` のキーワードで先行研究を検索（CiNii、Google Scholar）
2. ヒットした論文を `literature/notes/` にテンプレートに沿ってメモ化
3. 30〜50本ほど読んだ段階で `topic/research-question.md` を更新・絞り込み
4. 指導教員と題目について擦り合わせ（夏までに）
