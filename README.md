## ディレクトリ構成

```
university/
├── topic/              # テーマ絞り込み・題目候補
├── literature/         # 先行研究ノート
│   └── notes/          # 1論文1ファイル
├── sources/            # 一次資料メモ
│   ├── policy/         # 政策文書（文科省等）
│   ├── statistics/     # 統計データ（IB機構、JCIS等）
│   └── media/          # 新聞・雑誌記事
├── thesis/             # 本文作業
│   └── drafts/         # 章ごとの原稿
├── references.bib      # BibTeX 参考文献DB
└── schedule.md         # 進捗管理
```
