# テキスト分析メソッドノート

方向性 A+B のうち、B（テキスト分析）に関する準備メモ。実装開始前に整理しておく。

## ツール候補の比較

| ツール | 敷居 | 強み | 弱み |
|---|---|---|---|
| **KH Coder** | 低 | GUI、日本語論文での利用実績多数、出力が論文向き | 拡張性が低い、カスタム分析に弱い |
| **Python + MeCab/janome** | 中〜高 | 柔軟、gensim/scikit-learn 連携、再現性高い | 環境構築でつまずきやすい |
| **R + RMeCab/quanteda** | 中 | 統計解析と連携しやすい | 日本語処理の情報が Python より少ない |

**推奨**：まず **KH Coder** でパイロット分析 → 物足りなくなったら Python へ移行

## 想定する分析手法

### 1. 基本統計
- 期間別記事数の推移
- 文字数・語数の分布

### 2. 頻出語分析
- 単純頻度
- TF-IDF（時期ごとの特徴語抽出）

### 3. 共起ネットワーク
- 「インターナショナルスクール」と共起する語のネットワーク
- 時期別に分けて比較

### 4. 時期比較
- 2000-2005、2005-2010、2010-2015、2015-2020、2020-2025 の5区分
- 特徴語（chi-square、対数尤度比）
- Word2Vec などの分散表現で意味変化を追うことも可能（余裕があれば）

## データ収集の段取り

1. 大学図書館経由で以下のDBが使えるか確認
   - 日経テレコン
   - 朝日クロスサーチ（旧 聞蔵II）
   - 読売ヨミダス
   - 毎索（毎日新聞）
2. 検索式を決める
   - 主：「インターナショナルスクール」OR「インター校」
   - 関連：「IB」「国際バカロレア」「バイリンガル教育」
3. 記事データをテキストファイルに出力（コピペ／CSV等）
4. ノイズ除去（広告、見出し重複など）
5. KH Coder 等に投入

## 倫理・著作権の留意

- 新聞記事の全文は著作権があるため、原文をリポジトリにコミットしない
- 分析用データは `sources/media/` に置くが `.gitignore` で除外する構成も検討
- 論文本文では引用部分のみ、出典明示で使用

- 分析期間の妥当性
- サンプル数の目安
